## 📌 About the Internship

The internship focused on building practical, real-world C++ programming skills beyond academic coursework — covering procedural programming, object-oriented design, and algorithmic problem-solving through three fully working, independently tested console applications. Each project was designed, coded with thorough input validation, compiled with warnings enabled, and verified through actual test runs before being documented.

**Organization:** CodeAlpha — a software development company offering virtual internship programs across multiple technology domains, with a focus on innovation, performance, and scalable solutions.

## 🎯 Objectives

- Gain hands-on C++ experience beyond academic coursework
- Apply core programming concepts — loops, functions, arrays, structs — to real, working applications
- Learn and apply object-oriented programming (OOP) principles such as encapsulation and composition
- Understand and implement a classic algorithmic technique (recursive backtracking)
- Practice writing clean, modular, well-documented, and properly validated code
- Gain experience with the full software development cycle: design, code, test, debug, document
- Build a portfolio of verifiable, working projects suitable for a resume and technical interviews

## 💻 Projects Completed

| Task | Project | Description |
|---|---|---|
| 1 | **CGPA Calculator** | Calculates semester GPA and overall CGPA from course grades and credit hours, using structs, vectors, and full input validation |
| 3 | **Banking System** | OOP-based system (Customer, Account, Transaction, Bank classes) supporting deposits, withdrawals, fund transfers, and transaction history |
| 4 | **Sudoku Solver** | Solves any valid 9×9 Sudoku puzzle using a recursive backtracking algorithm on a 2D array |

> Of the four available C++ tasks, three were selected and completed in full, satisfying CodeAlpha's requirement of a minimum of two or three tasks. Task 2 (Login and Registration System) was evaluated but not selected, as plaintext file-based credential storage was assessed as inherently insecure for a portfolio-facing demonstration.
